# Product Manager Pro

Aplikasi web Full-stack yang memungkinkan pengguna untuk melakukan operasi CRUD (Create, Read, Update, Delete) pada data produk. 

## Tech Stack
- **Framework:** Next.js 
- **Database:** PostgreSQL (Neon)
- **ORM:** Prisma
- **UI Library:** Shadcn UI & Tailwind CSS
- **Validation:** Zod
- **Icons:** Lucide React
